# ThaparTrade

## A Campus Marketplace for the Thapar Community

ThaparTrade is a peer-to-peer marketplace designed specifically for the Thapar community. It provides students with an organized platform to discover, list, and exchange items within the campus community.

### Problem

Students currently rely on WhatsApp groups, personal contacts, social media, and other informal channels to buy and sell used items. These methods make it difficult to discover relevant listings, organize information, and establish trust between users.

### Proposed Solution

ThaparTrade provides a centralized marketplace where authenticated students can create and manage listings, browse available items, search and filter products, and report listings that are unauthorized or misleading. Administrators can review reported listings and take appropriate moderation actions.

### Key Features

- Student authentication and account management
- Create, edit, and delete listings
- Browse available listings
- Search and filter listings
- View detailed listing information
- Update listing status
- Report problematic or misleading listings
- Admin review and moderation of reported listings

### Users

**Student / User**
- Manage account and profile
- Browse and search listings
- Create and manage listings
- Report listings

**Admin**
- Review reported listings
- Remove inappropriate listings
- Restore listings when appropriate

### Project Goal

The goal of ThaparTrade is to provide a simple, organized, and community-focused marketplace that makes student-to-student trading easier and more reliable within Thapar.
