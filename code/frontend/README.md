# Thapar Trade

Final evaluation-ready frontend for the Thapar Trade project.

## Run
```bash
npm install
npm start
```

The homepage uses the supplied Thapar campus photograph as the hero background. The UI uses Thapar Trade branding throughout and includes marketplace browsing, search/filtering, saved items, authentication, listing creation, profile, How It Works and About pages.

Sample seller names include Rajbir Singh, Chitesh Jindal and Ishan Garg.
